# APU Hostel Home Appliances Service Centre (AHHASC)
A comprehensive Java-based backend and GUI application designed to manage appliance repair services for accommodation tenants in APU. The system involves different user types (managers, technicians, and customers) with functionalities like:
*   Appointment scheduling
*   Service tracking
*   Feedback management

---

## System Architecture
Built with Java, this project implements the four Object-Oriented Programming (OOP) pillars with modularity to improve the project's maintainability.  
*   Language: Java (JDK Compatible)
*   User Interface: Java Swing (JFrame, JTable, JScrollPane, Box Layout)
*   Data Storage: Text file
*   Core OOP Concepts: Encapsulation, Abstraction, Inheritance, and Modularity

---

## Prerequisities for Execution
*   Latest Java Development Kit (JDK)  
*   Ensure that the required `.txt` database files are located in the `src\textfile` directory.  
*   Include `datepicker-1.3.4.jar` in your build path/classpath.

---

## Core Features
The features for each user type are detailed as below:

### Manager / Administrator
*    Account Management: Create and modify user profiles across all access levels (Managers, Technicians, Customers).
*    Appointment Booking: Schedule appliance service appointments based on technician availability.
*    System Analytics: View aggregated ratings and individual customer feedback.
*    Inventory Control: Update the catalogue and pricing of serviced items.  

### Technician
*    Task Management: View daily assignments and overall historical service schedules.
*    Payment Tracking: Update payment statuses (Paid/Unpaid) for completed services directly from the dashboard.
*    Performance Review: Access personal service ratings and individualized customer feedback.  

### Customer
*    Service Tracking: View upcoming and historical service appointments using a unique TP number.  
*    Feedback Integration: Submit system ratings, technician ratings, and qualitative feedback for completed repairs.
